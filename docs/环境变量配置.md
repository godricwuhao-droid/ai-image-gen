## 一、环境变量清单

### 1.1 API密钥配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `OPENAI_API_KEY` | 是 | - | OpenAI API密钥 |
| `RELAY_API_KEY` | 是 | - | 中转API密钥 |
| `RELAY_API_BASE_URL` | 否 | `https://api.jiekou.ai/v3` | 中转API地址 |

### 1.2 数据库配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `DATABASE_URL` | 是 | - | 主数据库连接URL |
| `DATABASE_ROOT_URL` | 是 | - | Root数据库连接URL |

### 1.3 Redis配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `REDIS_URL` | 是 | - | Redis连接URL |
| `CELERY_BROKER_URL` | 是 | - | Celery消息队列URL |
| `CELERY_RESULT_BACKEND` | 是 | - | Celery结果后端URL |

### 1.4 MinIO对象存储配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `MINIO_ENDPOINT` | 是 | `minio:9000` | MinIO内部访问地址(Docker网络) |
| `MINIO_PUBLIC_URL` | 是 | `http://localhost:9000` | MinIO外部访问地址(浏览器访问) |
| `MINIO_ACCESS_KEY` | 是 | `minioadmin` | MinIO访问密钥 |
| `MINIO_SECRET_KEY` | 是 | `minioadmin` | MinIO私有密钥 |
| `MINIO_BUCKET` | 是 | `ai-images` | MinIO存储桶名称 |

### 1.5 安全配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `SECRET_KEY` | 是 | - | JWT签名密钥 |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | 否 | `1440` | Token过期时间(分钟) |

### 1.6 OpenAI配置

| 变量名 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `OPENAI_BASE_URL` | 否 | `https://api.openai.com` | OpenAI API地址 |

## 二、配置示例

### 2.1 .env 文件

```bash
# API密钥
OPENAI_API_KEY=sk-your-openai-key
RELAY_API_KEY=sk_your_relay_key
RELAY_API_BASE_URL=https://api.jiekou.ai/v3

# 数据库
DATABASE_URL=mysql+aiomysql://user:password@mysql:3306/dbname
DATABASE_ROOT_URL=mysql+aiomysql://root:password@mysql:3306/dbname

# Redis
REDIS_URL=redis://redis:6379/0
CELERY_BROKER_URL=redis://redis:6379/0
CELERY_RESULT_BACKEND=redis://redis:6379/0

# MinIO
MINIO_ENDPOINT=http://minio:9000
MINIO_PUBLIC_URL=http://localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=ai-images

# 安全
SECRET_KEY=your-super-secret-key-change-this-in-production
ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

## 三、配置说明

### 3.1 MINIO_ENDPOINT vs MINIO_PUBLIC_URL

| 变量 | 用途 | 使用场景 |
|------|------|---------|
| `MINIO_ENDPOINT` | Docker内部网络通信 | 后端服务连接MinIO |
| `MINIO_PUBLIC_URL` | 浏览器访问图片 | 前端显示图片URL |

```
浏览器 → MINIO_PUBLIC_URL (http://localhost:9000)
后端服务 → MINIO_ENDPOINT (http://minio:9000)
```

### 3.2 中转API地址配置

```bash
# 默认中转API
RELAY_API_BASE_URL=https://api.jiekou.ai/v3

# 如需更换其他中转服务商
RELAY_API_BASE_URL=https://your-relay-provider.com/v3
```

## 四、docker-compose.yml 环境变量

```yaml
services:
  backend:
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY:-sk-your-api-key-here}
      - RELAY_API_KEY=${RELAY_API_KEY:-sk-your-api-key-here}
      - RELAY_API_BASE_URL=${RELAY_API_BASE_URL:-https://api.jiekou.ai/v3}
      - MINIO_ENDPOINT=http://minio:9000
      - MINIO_PUBLIC_URL=http://localhost:9000
      - DATABASE_URL=${DATABASE_URL}
      - REDIS_URL=${REDIS_URL}
      - SECRET_KEY=${SECRET_KEY:-your-secret-key-change-this-in-production}
```

## 五、敏感信息管理

### 5.1 生产环境建议

1. **使用Docker Secrets** 或 **K8s Secrets** 存储敏感信息
2. **不要提交** `.env` 到版本控制
3. **定期轮换** API密钥

### 5.2 环境变量优先级

```
命令行参数 > .env文件 > docker-compose.yml默认值
```

## 六、故障排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 图片无法加载 | MINIO_PUBLIC_URL配置错误 | 检查环境变量是否为外部可访问地址 |
| 数据库连接失败 | DATABASE_URL格式错误 | 检查连接字符串格式 |
| Celery任务不执行 | REDIS连接失败 | 检查REDIS_URL配置 |
| API调用失败 | API_KEY无效 | 检查密钥是否正确 |
