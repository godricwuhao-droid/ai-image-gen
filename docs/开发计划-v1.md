#### 2. 真实支付系统

**目标**: 集成Stripe/支付宝等支付渠道

**数据库变更**:
```sql
CREATE TABLE payments (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    order_id BIGINT NOT NULL,
    payment_id VARCHAR(255),           -- 第三方支付ID
    payment_method VARCHAR(50),         -- stripe/alipay
    amount DECIMAL(10, 2),
    currency VARCHAR(10) DEFAULT 'USD',
    status VARCHAR(50),                 -- pending/paid/failed/refunded
    created_at DATETIME DEFAULT NOW(),
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (order_id) REFERENCES orders(id)
);
```

**后端API**:
```
POST /api/v1/payments/create              # 创建支付
GET  /api/v1/payments/{id}/status         # 查询支付状态
POST /api/v1/payments/{id}/webhook        # 支付回调
GET  /api/v1/packages                      # 获取套餐列表
```

**前端变更**:
- `PricingPage.tsx` - 添加真实购买流程
- 支付成功跳转到积分充值
- 订单历史页面

**工作量**: 8小时

## 二、技术架构升级

### 1. Redis缓存优化

```python
# 缓存热门图片
@router.get("/galleries/popular")
async def get_popular_galleries():
    cache_key = "popular_galleries"
    cached = await redis.get(cache_key)
    if cached:
        return json.loads(cached)
    
    # 查询并缓存
    result = await db.execute(select(Generation).where(...))
    await redis.setex(cache_key, 300, json.dumps(result))  # 5分钟缓存
    return result
```

## 三、DevOps优化

### 1. CI/CD流水线

```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Run tests
        run: docker-compose run backend pytest
  deploy:
    needs: test
    steps:
      - name: Deploy to server
        run: docker-compose up -d
```
