## 三、更新计划

### 核心原则：参数一致性

**前端 → 自有后端 API → Celery Worker → 中转站**

前端传递的参数必须与 Celery Worker 最终传给中转站的参数保持一致，确保用户体验和实际生成效果一致。

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌─────────┐
│  前端    │────▶│  自有后端    │────▶│ Celery Worker │────▶│ 中转站  │
│ (React)  │     │   (FastAPI)  │     │   (Python)   │     │(Relay)  │
└──────────┘     └──────────────┘     └──────────────┘     └─────────┘
     │                   │                    │                  │
     ▼                   ▼                    ▼                  ▼
   UI选项          参数验证/转换          参数透传           AI生成
   (用户选择)      (积分计算)            (relay_provider)   (最终结果)
```

#### 3.0.1 参数传递流程

| 层级 | 职责 | 说明 |
|:-----|:-----|:-----|
| **前端** | UI 收集用户选择 | 用户选择的 quality/size/background 等 |
| **自有后端 API** | 参数验证、积分扣除 | 校验参数合法性，扣除用户积分 |
| **Celery Worker** | 参数转换、调用中转站 | quality 映射、尺寸映射、透传所有参数 |
| **中转站** | 调用 AI 服务 | 实际执行图片生成 |

#### 3.0.2 参数一致性要求

1. **质量参数 (quality)**
   - 前端支持：`low`, `medium`, `high`
   - 后端存储：`medium`, `high`（直接存储，不做转换）
   - 中转站期望：`low`, `medium`, `high`（标准值）
   - **要求**：前端传递的值必须能直接透传到中转站

2. **尺寸参数 (size)**
   - 前端支持：7 种尺寸
   - 后端存储：原始值
   - 中转站期望：7 种标准尺寸
   - **要求**：前端选择的尺寸必须与中转站支持尺寸完全匹配

3. **背景设置 (background)**
   - 前端支持：`auto`, `transparent`, `opaque`
   - 中转站期望：同上
   - **要求**：参数值完全一致

4. **输出格式 (output_format)**
   - 前端支持：`png`, `jpeg`
   - 中转站期望：同上
   - **要求**：参数值完全一致

5. **压缩等级 (output_compression)**
   - 前端支持：0-100 整数
   - 中转站期望：同上
   - **要求**：仅 JPEG 格式时传递

#### 3.0.3 禁止行为

❌ **禁止在自有后端 API 层修改用户传递的参数值**  
（如：将 `high` 改为 `hd`，将 `medium` 改为 `standard`）

❌ **禁止在不同层级之间转换参数含义**  
（如：前端 `medium` 到后端变成 `standard`）

✅ **正确做法**：各层使用统一的参数值，必要时只在 relay_provider 做兼容映射

#### 3.2 更新 relay_provider.py

```python
# =====================================================
# 参数一致性原则：
# 前端 → 自有后端 → Celery Worker → relay_provider → 中转站
# 所有层级使用统一的参数值，relay_provider 仅做旧值兼容

# 完整的尺寸映射表（直接传递，无需转换）
SIZE_MAP = {
    # 标准尺寸直接透传
    "1024x1024": "1024x1024",
    "1024x1536": "1024x1536",
    "1536x1024": "1536x1024",
    "2048x2048": "2048x2048",
    "2048x1152": "2048x1152",
    "3840x2160": "3840x2160",
    "2160x3840": "2160x3840",
    # 旧尺寸兼容映射（仅兼容历史数据）
    "1024x1792": "1024x1536",    # 兼容旧版 1024x1792
    "1792x1024": "1536x1024",    # 兼容旧版 1792x1024
}

# 质量映射（仅兼容旧版本，新版直接透传）
QUALITY_MAP = {
    # 标准值直接透传（新版）
    "low": "low",
    "medium": "medium",
    "high": "high",
    # 旧值兼容映射（兼容历史数据）
    "standard": "medium",   # 旧版 standard -> 新版 medium
    "hd": "high",            # 旧版 hd -> 新版 high
}

def normalize_quality(quality: str) -> str:
    """规范化质量参数"""
    return QUALITY_MAP.get(quality, quality)  # 默认透传

def normalize_size(size: str) -> str:
    """规范化尺寸参数"""
    return SIZE_MAP.get(size, "1024x1024")  # 默认 1024x1024
```

#### 3.3 更新积分计算逻辑

**文件**：`backend/app/tasks/generate_image.py`

```python
CREDITS_MAP = {
    # 质量 -> 尺寸 -> 积分
    "low": {
        "1024x1024": 1,
        "1024x1536": 1,
        "1536x1024": 1,
        "2048x2048": 2,
        "2048x1152": 1,
        "3840x2160": 2,
        "2160x3840": 2,
    },
    "medium": {
        "1024x1024": 10,
        "1024x1536": 8,
        "1536x1024": 8,
        "2048x2048": 20,
        "2048x1152": 8,
        "3840x2160": 19,
        "2160x3840": 19,
    },
    "high": {
        "1024x1024": 40,
        "1024x1536": 32,
        "1536x1024": 32,
        "2048x2048": 81,
        "2048x1152": 32,
        "3840x2160": 76,
        "2160x3840": 76,
    },
}

def calculate_credits_cost(quality: str, size: str, n: int = 1) -> int:
    """计算积分消耗"""
    quality = QUALITY_MAP.get(quality, "medium")
    size = SIZE_MAP.get(size, "1024x1024")
    credits_per_image = CREDITS_MAP.get(quality, {}).get(size, 10)
    return credits_per_image * n
```

## 七、注意事项

### 7.1 参数一致性原则
- 前端传递的值必须与 relay_provider 传给中转站的值保持一致
- 质量参数直接使用：`low`, `medium`, `high`
- 禁止使用：`standard`, `hd`（旧值）
- 兼容映射只在 relay_provider 层处理历史数据

### 7.2 向后兼容
- 质量参数：`standard` → `medium`，`hd` → `high`（仅 relay_provider 处理）
- 尺寸参数：`1024x1792` → `1024x1536`，`1792x1024` → `1536x1024`（仅 relay_provider 处理）
- 旧版本 API 请求需正确转换参数

### 7.3 JPEG 限制
- PNG 格式时 `output_compression` 必须为 100 或不传
- 选择 JPEG 时透明背景选项需禁用

### 7.4 透明背景
- 仅 PNG 格式支持
- 选择 JPEG + 透明时需提示用户

### 7.5 大尺寸限制
- 3840x2160 / 2160x3840 生成时间 60-120 秒
- 需添加预计等待时间提示
- 考虑添加进度回调

### 7.6 内容审核
- `moderation=low` 可能返回更多成人/敏感内容
- 需添加使用提示和免责条款
