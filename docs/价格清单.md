## 3. 价格说明

### 质量等级
- **low (基础质量)**: 适合快速预览，价格最低
- **medium (中等质量)**: 平衡速度和质量，性价比最高
- **high (高质量)**: 最佳细节和清晰度，价格最高

### 尺寸规格
- 支持多种常见尺寸，从 1024x1024 到 3840x2160
- 非标准尺寸可能无法生成

### 计费方式
- 按次计费，每次生成 N 张图片按 N 次计算
- 失败任务根据策略可能退还积分
