#### T1: 历史记录公开功能 ⏱️ 2小时

**需求**: 用户可将历史记录中的图片设为公开，发布到画廊展示

**后端任务**:
- 在 `generations.py` 新增 `PUT /{id}` 接口
- 支持 `is_public` 字段更新

**前端任务**:
- 在 HistoryPage 添加"公开/取消公开"按钮

---

#### T2: 积分系统API ⏱️ 3小时

**需求**: 用户积分余额管理、充值、消耗查询

**后端任务**:
- 新建 `credits.py` 路由
- `GET /balance` - 获取积分余额
- `POST /add` - 管理员充值
- `POST /deduct` - 生成图片时扣减

**数据库**:
```sql
-- credits表已有users关联
ALTER TABLE users ADD COLUMN credits INT DEFAULT 0;
```

---

#### T3: 支付系统API ⏱️ 4小时

**需求**: Stripe支付集成

**后端任务**:
- 新建 `packages.py` - 套餐管理
- 新建 `orders.py` - 订单管理
- Stripe Checkout 集成

**数据库**:
```sql
CREATE TABLE packages (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    credits INT NOT NULL,
    price DECIMAL(10, 2) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE
);

CREATE TABLE orders (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    package_id BIGINT,
    amount DECIMAL(10, 2) NOT NULL,
    credits INT NOT NULL,
    payment_status VARCHAR(50) DEFAULT 'pending',
    stripe_session_id VARCHAR(255)
);
```
