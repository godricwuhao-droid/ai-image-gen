# 管理后台启动指南

## 问题诊断与修复

### 问题1: API 404错误
**症状**: 访问 http://localhost:8001 时报错 `Failed to fetch stats: AxiosError: Request failed with status code 404`

**原因**: 生产环境中前端无法访问 `localhost:8000`（因为在Docker容器内），需要通过nginx代理访问后端

**解决方案**:
1. ✅ 更新 `api.ts` - 添加生产环境判断，使用相对路径
2. ✅ 更新 `nginx.conf` - 配置API代理到后端服务
3. ✅ 更新 `Dockerfile` - 使用nginx作为生产服务器

### 问题2: 图标不存在错误
**症状**: `CreditOutlined` 图标不存在

**原因**: `@ant-design/icons` 没有 `CreditOutlined` 图标

**解决方案**:
1. ✅ 替换为 `DollarOutlined` 图标
2. ✅ 更新所有相关文件

## 启动步骤

### 1. 重新构建并启动服务

```bash
# 进入基础设施目录
cd /data/ai-image/ai-image-gen/infrastructure

# 重新构建admin镜像（已修复）
docker-compose build admin

# 启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps
```

### 2. 验证服务启动

```bash
# 检查admin服务
docker-compose logs -f admin

# 检查backend服务
docker-compose logs -f backend
```

### 3. 访问管理后台

- **管理后台**: http://localhost:8001
- **后端API**: http://localhost:8000
- **API文档**: http://localhost:8000/docs

## 故障排查

### 问题: 服务启动后仍然404

**检查步骤**:

1. 检查Docker容器是否正常运行:
   ```bash
   docker-compose ps
   ```

2. 检查admin日志:
   ```bash
   docker-compose logs admin
   ```

3. 检查backend是否正常:
   ```bash
   docker-compose logs backend
   ```

4. 确认nginx配置是否正确:
   ```bash
   docker exec ai_image_admin cat /etc/nginx/conf.d/default.conf
   ```

5. 测试容器内网络:
   ```bash
   docker exec ai_image_admin ping backend
   ```

### 问题: 登录后仍然报错

**检查步骤**:

1. 确认浏览器使用的是生产环境（非localhost开发）
2. 清除浏览器缓存
3. 检查Token是否正确存储在localStorage中
4. 检查浏览器开发者工具Network标签
