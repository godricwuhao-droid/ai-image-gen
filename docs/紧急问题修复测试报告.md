## 二、问题1：模板"使用"按钮修复

### 2.1 问题描述
用户点击模板页面的"使用"按钮后无响应，无法将模板的prompt填入主页输入框。

### 2.2 问题原因
HomePage组件的useEffect依赖数组不完整，只包含了`location.pathname`而不包含`location.state`，导致state变化时不会触发effect执行。

### 2.3 修复方案
```typescript
// 修改前
}, [error, location.pathname]);

// 修改后
}, [error, location.state]);
```

## 三、问题2：收藏状态显示完善

### 3.1 问题描述
用户无法区分画廊中哪些图片已收藏、哪些未收藏，收藏按钮状态不明确。

### 3.2 问题原因
GalleryPage未获取用户收藏列表，导致无法显示收藏状态。

### 3.3 修复方案
1. 新增`favoriteIds`状态存储用户收藏的generation_id集合
2. 页面加载时调用`fetchFavorites()`获取用户收藏列表
3. 创建`handleToggleFavorite()`函数实现收藏/取消收藏切换
4. UI显示：
   - 已收藏：红色实心心形图标 (`HeartIconSolid`)
   - 未收藏：白色空心心形图标 (`HeartIcon`)
   - 弹窗中显示"已收藏"/"收藏"文本

### 3.4 核心代码
```typescript
const [favoriteIds, setFavoriteIds] = useState<Set<number>>(new Set());

const fetchFavorites = useCallback(async () => {
  if (!isAuthenticated) return;
  const data = await favoriteService.getList(1, 100);
  const ids = new Set(data.favorites.map(f => f.generation_id));
  setFavoriteIds(ids);
}, [isAuthenticated]);

const handleToggleFavorite = async (generationId: number) => {
  const isFavorited = favoriteIds.has(generationId);
  try {
    if (isFavorited) {
      await favoriteService.remove(generationId);
      setFavoriteIds(prev => {
        const next = new Set(prev);
        next.delete(generationId);
        return next;
      });
      toast.success('已取消收藏');
    } else {
      await favoriteService.add(generationId);
      setFavoriteIds(prev => new Set(prev).add(generationId));
      toast.success('已添加到收藏');
    }
  } catch (error) {
    toast.error(isFavorited ? '取消收藏失败' : '收藏失败');
  }
};
```

## 四、问题3：XSS安全漏洞修复

### 4.1 问题描述
用户输入的prompt内容未转义直接渲染，存在XSS攻击风险。

### 4.2 风险分析
**攻击场景**：
```javascript
// 恶意prompt示例
<img src=x onerror="alert('XSS')">)

// 或
<script>document.cookie</script>
```

### 4.3 修复方案
1. 创建转义工具函数 `src/utils/escape.ts`
2. React JSX默认转义：检查项目中没有使用 `dangerouslySetInnerHTML`
3. 确保所有prompt通过JSX文本节点渲染

### 4.4 安全检查结果

| 检查项 | 结果 |
|--------|------|
| dangerouslySetInnerHTML | ❌ 未使用 |
| innerHTML直接赋值 | ❌ 未使用 |
| JSX文本渲染 | ✅ 安全 |
| React自动转义 | ✅ 启用 |

### 4.5 XSS测试用例

| 用例ID | 测试输入 | 预期行为 | 实际结果 |
|--------|---------|---------|---------|
| T3.1 | `<script>alert(1)</script>` | 显示为纯文本 | ✅ 通过 |
| T3.2 | `<img src=x onerror=alert(1)>` | 显示为纯文本 | ✅ 通过 |
| T3.3 | `javascript:alert(1)` | 显示为纯文本 | ✅ 通过 |
| T3.4 | 正常prompt | 正常显示 | ✅ 通过 |
