## 技术栈

### 前端
- React 18 + TypeScript
- Vite 构建工具
- Tailwind CSS (自定义主题)
- Heroicons 图标库
- React Router (路由)
- Zustand (状态管理)
- React Hot Toast (提示)

### 后端
- Python FastAPI
- SQLAlchemy + MySQL
- Redis (缓存/Celery)
- MinIO (对象存储)
- Celery (异步任务)

### 容器化
- Docker + Docker Compose
- 8个服务容器

## 重要配置

### OpenAI API Key ⚠️

当前配置的是占位符，需要配置真实密钥：

```bash
# 查看当前配置
docker exec ai_image_backend env | grep OPENAI

# 修改docker-compose.yml中的OPENAI_API_KEY
# 或设置环境变量后重启
docker-compose up -d --build backend celery-worker
```
